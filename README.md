# ImageSlide Player

Prototype de PWA de diaporama.

## Test rapide

1. Ouvrir le dossier dans VS Code.
2. Installer l'extension Live Server.
3. Clic droit sur `index.html`.
4. Choisir `Open with Live Server`.
5. Sélectionner un dossier contenant des images.
6. Choisir la durée.
7. Cliquer sur `Lancer`.

## Fonctionnalités actuelles

- Sélection d'un dossier d'images
- Filtrage des fichiers image
- Tri naturel des noms
- Aperçu de la première image
- Statistiques
- Durée mémorisée
- Lecture automatique
- Pause / reprise
- Image précédente / suivante
- Rejouer
- Plein écran
- Écran À propos
